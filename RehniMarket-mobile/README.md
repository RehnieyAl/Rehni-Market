# RehniMarket Mobile

App móvil de RehniMarket, construida con Expo + Expo Router + TypeScript.

## Requisitos

- Node.js
- pnpm
- Expo Go (Android) para pruebas rápidas

## Desarrollo

```bash
pnpm install
pnpm exec expo start --lan --port 8085
```

Escanea el QR con Expo Go en Android.

## Estructura

```
src/app/     Rutas (Expo Router)
assets/      Íconos y splash
```
